Seven Window Design Notes

One web page, three looks, eight muted palettes. This is the window as the code builds it, written 4 Nov 2026 from seven/window/page/ and the desktop's saved settings.

It describes the code, not a screenshot: nobody has checked it by eye for this document, and several recent pages are still unseen in the project notes.

Why the laptop can look different

The desktop's look is not in the repository. It comes from two Windows variables and three state files, so a laptop with the same code opens in the plain classic look, in Edge.

Only state/model_mode.json is tracked by git. To match the desktop, set SEVEN_UI=aurora, install Electron (npm install in seven/window-shell, or set SEVEN_ELECTRON) with SEVEN_SHELL=electron, and copy the three state files. seven/scripts/apply-look.ps1 (step 10 of laptop-setup.ps1) now does this from seven/config/desktop-look.json, which export-look.ps1 writes on the desktop. The old laptop app, Seven-L1, was a different program.

Three looks, one structure

The server writes the look into the <html> tag; everything else is CSS on those attributes.

classicdata-ui="classic" · style.css

Plain panels, system colours, light or dark by the system. The default.

glassdata-ui="glass" · glass.css

The slick look: warm paper tones, rounded controls, a draggable chat list, resizable table columns. Palettes live here.

auroradata-look="aurora" · aurora.css

Glass in blue, plus the hero avatar, the Command Center home and a hero strip on every page. A chosen palette replaces the blue.

The desktop is aurora with the graphite palette: graphite colours inside aurora's structure.

Pieces

  • Rail: the "SEVEN" tile widens it to show key names; buttons radius 12, current page filled with the accent and a glow.
  • Views: Chat, Forex, Notebook, Lab, REA, API, Settings. Settings has sections Settings, Memory, Plugins, Companion, Prompts.
  • Command Center (aurora home): grid areas hero quick / hero health / mission chats / positions positions, gap 16, cards radius 20.
  • Kept in the page only: the stage always keeps 648 px (a 320 px inspector and a 320 px chat plus 8 px margin); table columns never under 40 px. A reload restores the default layout.

Colour

Everything is a CSS custom property with the same meaning in every look: --ink text, --paper page, --panel, --line, --soft secondary text, --accent / --on-accent, --good, --bad, --warn. Gain is green and loss is red in every look.

Desk pages also declare Orbitron, Rajdhani (400–700) and Share Tech Mono from window/fonts/ (open licence). Which element uses which was not checked.

Components

  • View button / chip switch: soft text; on = accent fill, on-accent text, accent glow.
  • Cards: glass fill, 1px inset edge, a top highlight, radius 18–20, shadow. The approval card enters with a short animation.
  • Say row: one rounded glass bar: input, Send (accent), Stop (soft fill).
  • Tables: every header cell has a drag grip; widths are kept per table and column in the page.
  • Foldable cards on Forex and Notebook; the folded state is remembered in the browser store.

Desk keys (Forex, Notebook, REA, API, guide)

These pages share the desk vocabulary: a brand block ("SEVEN" over a small label), an F-key bar of numbered keys, and keys with cut corners. Under glass and aurora the cut corners become border-radius: 10px and the desk tokens follow the global theme.

Cut-corner keyRounded keyCurrentGoStop

Forex page rules Ray set: reports first, manual tools tucked away; a chart that pans and zooms with the mouse, a crosshair with a price tag, timeframe, indicator and line keys, OANDA's feel without its dark look; sub-tabs instead of one long page.

Hero avatar and motion

  • Orb 170 px in the strip (112 px under 760 px window height); the big hero card is the Command Center's, and the same orb moves into the strip elsewhere.
  • Settings: strip on/off and size, voice-reactive, backing, breathe, speed, colour (desktop: custom, hue 251), line style (glow).
  • The hero reacts to Seven's replies (glow and flash, "Thinking" / "Replying"); the mood part is hard to see.
  • prefers-reduced-motion turns the card entrance and orb motion off.

Responsive and access

  • Grids drop to one column at 900 px (Forex, prompts, API) and 760 px (Command Center); the hero shrinks under 760 px height. There is no phone layout.
  • prefers-color-scheme picks light or dark unless the Light/Dark button or a palette overrides it.
  • The rail has a label and aria-expanded; grips are labelled separators, keyboard-focusable, 24 px per arrow key; Settings sections are a tablist.

Known gaps for a designer

  • Forex and Notebook were split into sub-views to reduce crowding; the result has not been seen in Ray's own window.
  • Classic and Seven-L1 are older than aurora: design new screens for aurora plus the eight palettes.
  • Palettes are light only. The desktop's saved theme is dark; which wins on screen should be settled by looking.
  • The laptop needs the settings in the first section before it can be compared with the desktop.
